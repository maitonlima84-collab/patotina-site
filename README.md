# Patotina — site da escolinha

Protótipo estático do site do **Patotina Esporte Clube** (Matutina/MG), com foco na
Escolinha de Futebol. Publicado no GitHub Pages para apresentação à diretoria.

- Turmas e horários das três categorias (4–6, 7–9, 10+)
- Pré-matrícula que abre a mensagem pronta no WhatsApp do professor
- Títulos, método, história do time, APEC e parceiros

Sem build: HTML, CSS e JS puros. Basta abrir `index.html` ou servir a pasta.
